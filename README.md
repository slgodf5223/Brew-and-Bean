# Brew-and-Bean 

CSCI 3000: Web Programming Project

## Description

The purpose of this project was to exercise student collaboration and showcase learning objectives for CSCI 3000 utilizing HTML, CSS, and Java Script. The website incorporates critical fundamentals for effective and user friendly web design demonstrating our understanding of the coursework. 

## Getting Started

No installation or set-up is required

To view our website:
1. Download this repository
2. Open ‘index.html’ in any web browser

The site will load and you’re ready to explore!

## Key Features 

* Interactive Menu
* Location and Hours
* Easy Online Ordering
